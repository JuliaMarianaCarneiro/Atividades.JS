💻 Atividades JavaScript

Neste repositório estão algumas atividades desenvolvidas durante as aulas de JavaScript. Os exercícios foram feitos para praticar os principais conceitos de programação, como variáveis, funções, estruturas de repetição (for), cálculos e console.log.
As atividades ajudam a desenvolver a lógica de programação e entender melhor como o JavaScript funciona na prática.
Exemplo: uma das atividades cria as tabuadas de 1 até 10 utilizando funções e estruturas de repetição.
